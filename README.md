# Design and Performance Evaluation of a Custom Application-Layer Protocol for Low-Latency IoT Sensor Data Exchange

This project explores the design and performance evaluation of a custom application-layer protocol for low-latency IoT sensor data exchange using Python, UDP sockets, and simulated sensors only.

## Setup

Create a virtual environment and install the project dependencies:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```
